# Osobola Course 2 — Welcome

This presentation is based on `intro to osobola.mp3`. The recording covers the course welcome, beginner expectations, AI and coding tools, the course learning approach, website ownership, learner independence, and the setup lesson coming next.

Open `index.html` in a modern browser to present. The deck is self-contained and works offline.

## Controls

- **Right arrow**, **Space**, or **Page Down**: next slide
- **Left arrow** or **Page Up**: previous slide
- **Home / End**: first / last slide
- Use the slide grid for direct navigation, or the full-screen button for presenting.
- On touch screens, swipe left or right to move between slides.
